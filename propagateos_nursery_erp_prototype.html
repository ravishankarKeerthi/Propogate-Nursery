A health incident can trigger quarantine, block picking and dispatch, create treatment tasks, record material consumption and require a clearance inspection.

Health control rules

  • Suspected disease: quarantine affected batch or location.
  • Mortality: record quantity, cause category and evidence.
  • Treatment: capture approved input, dose, operator and date.
  • Release: authorised inspection required before stock becomes available.
  • Repeated incidents: escalate to nursery manager.

Grade disposition logic

Grade A Meets full customer / catalogue specification; saleable.

Grade B Acceptable for alternate market or discounted sale; separate price list.

Rework Needs additional growing time or corrective care; return to growing stage.

Reject Not commercially usable; record disposal or recovery route.

Grading is a controlled stock transaction: accepted quantity moves to saleable inventory, rework stays in WIP, and rejected quantity is written off only with reason and approval.

Inventory availability formula

Costing design rules

  • Accumulate direct material, labour, utilities and overhead by batch.
  • Capture loss quantity and loss reason at each biological stage.
  • Calculate cost per saleable unit using accepted saleable output, not starting quantity.
  • Rework cost remains attached to the original batch genealogy.
  • Define accounting policy for WIP, biological assets and write-offs with finance / audit advisers.
Illustrative only: the prototype uses a simple batch cost allocation. Production accounting policy, tax treatment and applicable biological-asset standards require jurisdiction-specific configuration.

Detailed transaction flow

1. Plan & prepare

Forecast demand → review saleable stock and WIP → calculate production gap → confirm mother stock / seed availability → reserve growing capacity → approve propagation plan.

2. Create propagation batch

Select plant and cultivar → method → source lot / mother plant → input quantity → growing location → planned stage dates → expected yield → create batch ID and traceability record.

3. Execute biological stages

Record stage entry → task schedule → care activities → environment observations → stage inspection → mortality and loss reconciliation → stage transfer approval.

4. Manage crop health

Observe symptoms → log incident → isolate affected quantity → diagnosis → treatment approval → application and follow-up → clearance inspection or disposal.

5. Grade & release

Create grading lot → inspect sample / full quantity as configured → record grade-wise quantities → approve Grade A / B, rework and reject → release accepted quantities to saleable inventory.

6. Fulfil & close

Quote → customer order → ATP check → reservation → pick → dispatch inspection → delivery → invoice → receipt → batch profitability and yield review.
